# Phoenix PvP

A fire / hell / phoenix themed PvP resource pack for Minecraft 1.21 – 1.21.11.

## What's in it so far

| Texture | Look |
| --- | --- |
| Diamond sword | **Phoenix Blade**: the vanilla sword recoloured white-hot, yellow, orange and red; vanilla wooden grip |
| Netherite sword | **Hellfire Blade**: the vanilla sword in deep crimson, black and lava orange |
| Enchantment glint (items and armor) | The vanilla glint pattern, tinted orange instead of purple |

It's a vanilla edit: every texture keeps the exact vanilla pixels and shading, only the colours change.

## Install

Download `PhoenixPvP.zip` from the `phoenix-pack-latest` release (built automatically on every push),
drop it into `.minecraft/resourcepacks`, and enable it under Options → Resource Packs.

To build the zip yourself, zip the *contents* of this folder (`pack.mcmeta`, `pack.png`, `assets/`),
not the folder itself.

## Editing

The textures are generated by `tools/generate.py` (Python 3 with Pillow and NumPy). It downloads the
vanilla 1.21.11 textures and recolours them:

```sh
python3 phoenix-pack/tools/generate.py
```

It rewrites the PNGs under `assets/` and `pack.png`, and puts enlarged previews in `tools/preview/`.
Each sword's colours are a dark-to-bright ramp (`PHOENIX`, `HELLFIRE`) at the top of the script;
the glint colour is `GLINT_HUE`.
