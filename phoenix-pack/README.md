# Phoenix PvP

A fire / hell / phoenix themed PvP resource pack for Minecraft 1.21 – 1.21.11.

## What's in it so far

| Texture | Look |
| --- | --- |
| Diamond sword | **Phoenix Blade**: white-hot tip cooling to orange and red, with a phoenix-wing guard and an ember pommel |
| Netherite sword | **Hellfire Blade**: same shape in deep crimson and black |
| Enchantment glint (items and armor) | Orange fire streaks instead of the vanilla purple |

## Install

Download `PhoenixPvP.zip` from the `phoenix-pack-latest` release (built automatically on every push),
drop it into `.minecraft/resourcepacks`, and enable it under Options → Resource Packs.

To build the zip yourself, zip the *contents* of this folder (`pack.mcmeta`, `pack.png`, `assets/`),
not the folder itself.

## Editing

The textures are generated by `tools/generate.py` (Python 3 with Pillow and NumPy):

```sh
python3 phoenix-pack/tools/generate.py
```

It rewrites the PNGs under `assets/` and `pack.png`, and puts enlarged previews in `tools/preview/`.
Colours for each sword live in the `PHOENIX` and `HELLFIRE` tables at the top of the script.
