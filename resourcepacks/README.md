# Phoenix PvP resource pack

Minecraft Java 1.21.11 (pack format 75).

- `PhoenixPvP/` – pack source
- `PhoenixPvP.zip` – ready to drop into `.minecraft/resourcepacks`
- `tools/` – generators for the textures (`python3 tools/gen_fiery_netherite_sword.py`, needs Pillow)

Textures so far:
- Netherite sword – animated fiery netherite blade
